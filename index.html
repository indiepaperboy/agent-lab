A loop, made visible.
An agent gets a goal, chooses a tool, reads its result, and decides what to do next. The application executes the tool; the decision maker uses the returned evidence.
Step advances exactly one event. A TOOL event only shows a request; the following OBSERVE event executes it. Auto runs that same loop at a readable pace. Raw events reveals structured actions, arguments and results.
Guided rehearsal uses a fixed, authored investigation with real queries over the bundled files. It demonstrates the mechanics, not autonomous AI.
Local AI downloads a model and runs it on your browser’s GPU. It receives the task and tool descriptions, then chooses its own path. Requires WebGPU, HTTPS or localhost, internet for the initial download, and several GB of available memory. No API key or inference server. Small models can make mistakes; inspect the evidence.
Decisions shown here are concise action summaries, never hidden chain-of-thought. All records describe a fictional company.
