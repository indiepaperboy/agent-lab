Where the LLM fits.

This is a simulated walkthrough. Example spreadsheets and scripted LLM choices are included in the page. There are no uploads, model downloads, accounts or API keys.

The application gives the LLM a job. It supplies instructions, a menu of tools and the results returned so far. In a real agent, the model uses that context to generate the next tool request. Here we show a prepared example of those choices.

Code matches references and calculates costs. A unique exact reference with a nonblank cost centre can be allocated. Missing references, missing cost centres and duplicate matches are exceptions.

The LLM investigates the gaps. It can choose a search using a row’s description and record candidate matches for review. A plausible match cannot silently assign a cost centre.

Step reveals one event with what, how and why. Auto advances every eight seconds. Raw events shows the example requests and actual local tool results. Restart clears the lesson and review notes.

All records are fictional. Calculations run in the browser. No payment matching or accounting entries are performed.
